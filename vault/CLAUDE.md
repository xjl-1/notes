- # CLAUDE.md

  这是一个以学习、设计、技术与个人成长为核心的个人知识库。请用中文协助我整理、检索、总结和连接笔记。

  ## Vault结构

  - `00 InBox/`：临时收件箱，存放未分类、未整理内容。
  - `知识笔记/`：长期知识笔记，存放课程、技术、设计、阅读、软件工具等可复用内容。
  - `项目笔记/`：项目相关的目标、过程、方案、汇报、复盘和索引，不作为大型文件仓库。
  - `素材剪藏/`：网页剪藏、摘录、外部资料，整理后可提炼到知识笔记或项目笔记。
  - `每日记录/`：日记、每日学习记录、生活观察、阶段性反思。
  - `Dataview/`：用于放置索引页、统计页、动态看板和查询页面。
  - `模板/`：Obsidian模板文件，不作为普通笔记整理。

  ## 基本规则

  - 优先保留原文，不要删除、覆盖或擅自大幅改写我的原始记录。
  - 文件夹表示内容所属领域，`type` 表示笔记类型，`status` 表示当前状态。
  - 不确定放哪里时，先放入 `00 InBox/`，或询问我。
  - 不要擅自批量重命名、移动文件或重构文件夹。
  - 可以添加标签、摘要、双向链接、frontmatter，并提出整理建议。
  - 项目中的大型文件、图片、PPT、Word、模型文件等不强制放入Vault，可在笔记中保留路径或说明。
  - 重要文件夹可以有 `index.md`，用于说明用途、关键文件和整理规则，但不要写成长目录。

  ## 默认frontmatter

  ```yaml
  ---
  title: 
  tags: []
  created: YYYY-MM-DD
  type: note
  status: active
  summary: 
  ---
  ```

  常用 `type`：

  - `note`：知识笔记
  - `project`：项目笔记
  - `daily`：每日记录
  - `clipping`：素材剪藏
  - `index`：索引页
  - `template`：模板

  常用 `status`：

  - `active`：正在使用
  - `in-progress`：进行中
  - `done`：已完成
  - `archived`：已归档或暂时不用

  ## 整理原则

  整理内容时，优先判断它属于：临时内容、长期知识、项目笔记、素材剪藏、每日记录或索引页面。

  从日记、剪藏、项目记录中发现有长期价值的内容时，可以建议提炼为新的知识笔记，并建立双向链接。

  保持结构稳定，不要因为短期兴趣或单篇笔记而重构整个Vault。
