# 问题大全

## 无法登录校园官方网站

1. "设置"中针对连接的 WLAN，"随机硬件地址"设置为"开"
2. 控制面板→网络和 Internet→网络和共享中心，点击左边"更改适配器设置"，查看是否有其他连接，禁用
3. 控制面板→网络和 Internet→网络和共享中心，点击左边"更改适配器设置"，右键连接的网络→"属性"，双击"Internet 协议版本4 (TCP/IPv4)"，改为"自动获得 IP 地址"
4. Edge 浏览器"设置"→"重置设置"（最终手段）
