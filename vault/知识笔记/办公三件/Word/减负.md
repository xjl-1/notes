# 快速制表
- Tab 键
- 制表符（开"标尺"视图的情况下，在最左侧上边）
	- 左对齐，右对齐，居中对齐
- 格式刷应用相同位置制表符
- 对于符号要求：段落-制表位（左下角）


# 自动更正
- 文件-选项-
- 校对-自动更正选项-替换-
	- 图片，带格式文本均可
	- Ctrl+Z：避免自动更正
	- 类似剪切板功能


# 合并文档
- 插入-对象-
- 文件中的文字
	- 注意每个文档文件名前缀以数字顺序排序
	- 首个为 01


# 自带模板
- 文件-更多模板-
	- 更改配色：设计-颜色


# 缩进  
- 标尺-上方标尺-
- 左侧滑块
	- 上滑块-首行缩进
	- 下滑块
		- 左缩进（整个段落缩进）
		- 悬挂缩进（除首行外的文字缩进）
- 右侧滑块
	- 右缩进（整个段落缩进）
- 回车
	- 硬回车（段落标记）
	- 软回车（换行不换段）:Shift+enter
#首行自动空两格成功远离每段敲敲敲

# 三种输入 
- 插入模式
- 即点即输模式
- 改写模式（会覆盖后面的文字）
	- 在界面左下角改变模式
#为什么打完的字会把后面的字吞掉

# 空白页删除 
- 调整页边距
	- 标尺
	- 左侧箭头调整
- 调整段落行间距（适合表格）
#最后一页怎么就是删不掉


# 段落分页
 - 右键-段落-换行与分页
	 - 保持段落连续性
		 - 与下段同页
		 - 段中不分页
	 - 保持段落独立性
		 - 段前分页
#删不掉的小黑点原来是段落格式


? 为通配符，例如文档中
P 1 xxxxxxxx
P 2 xxxxxxx
P 3 xxxxxxx
查找替换，查找：P?
