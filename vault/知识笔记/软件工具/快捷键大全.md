# 快捷键大全

## 电脑系统自带

- `Ctrl+Shift+Esc`：打开任务管理器
- `Ctrl+N`：新建文件
- `Ctrl+O`：打开文件
- `Ctrl+S`：保存文件
- `Ctrl+Shift+S`：另存为
- `Ctrl+C/V`：复制粘贴
- `Ctrl+X`：剪切
- `Ctrl+Z`：撤销
- `Ctrl+Y`：反撤销
- `Ctrl+Shift+T`：恢复最近关闭的文件路径或浏览器网页
- `Ctrl+Shift+4/2/6/8`（数字键开启）：相当于移动键
- `Win+E`：文件资源管理器
- `Win+v`:  剪切板
- `Win+I`：设置
- `Win+D`：显示桌面（再按一次恢复）
- `Win+方向键`：窗口显示位置
- `Win+.`：表情/特殊符号
- `Win++/-`：放大镜/缩小镜
- `Win+P`：屏幕设置
- `Win+Tab`：切换页面
- `Win+方向键`：自动分屏
- win+c/s/q:  搜索
- win+x:  相当于右键win图标
- win+z:  分屏方案
- win+k:  投放
- win+P:  投影
- win+h:  语音输入
- win+d:  回到桌面
- win+a:  右下角设置小面板
- win+t:  重复按加上回车可以调入其他窗口
- `Alt+F4`：关闭窗口
- `Alt+Enter`：查看文件属性
- `Ctrl+W`：关闭当前页面/浏览器网页
- `Ctrl+F5`：强行刷新网页
- `Shift+Delete`：永久删除文件
- `Shift+Alt`：改变输入法
- `Shift+F5`：Word 文档跳转至上次阅读的位置
- `Fn+F10`：开关电脑触摸板
- `Ctrl+Alt+Del`：进入安全界面，紧急重启
- `Shift+"重启"`：进入高级启动，可以使用 PE
- 打开任务管理器后，点击"运行新任务" + 按住 `Ctrl`：打开 CMD 窗口

### 缩放

- `Ctrl++/-`：放大/缩小
- `Ctrl+Shift++/-`：使用上标/下标
- `Ctrl+Alt+-`：可选连字符
- `Shift+Alt+-`：不间断连字符

### 纯文本粘贴方法

**方法 1（通用稳定）**：复制后按 `Ctrl+Alt+V` → `T` → 回车

- `Ctrl+Alt+V`：打开"选择性粘贴"
- `T`：Text（文本）
- `Enter`：确认

**方法 2（菜单键流）**：`Alt` → `H` → `V` → `T`

**方法 3（右键菜单）**：复制后 `Ctrl+V` → `Ctrl` → 然后按 `T`

### 快速调用 Word 文字模板

选中一段文字 → 插入→文本→文档部件→自动图文集→将所选内容保存到自动图文集库。下次调用时，输入保存时的标题，`Enter` 即可调用。
