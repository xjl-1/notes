数据分析综合学习笔记，涵盖 Excel、PowerBI、Tableau、MySQL 与 Python 基础

数据分析学习笔记#

前导课：基础实操#

实战案例：如何用 Excel"爬取"3000 套房源数据#

导入数据避坑指南#

  1. 表格数据导入：谨慎选择粘贴格式（公式的情况）
  2. 非表格数据导入：多技巧综合灵活运用

贝壳网数据复制粘贴流程：

  1. 粘贴到记事本（或其他软件上，只要是粘贴的格式是纯文本即可）
  2. 导入 Word 里面
  3. 用"替换"将"换行符（即 ^p）"改为 |||，将 /平 改为 /平^p（一个房源一行）
  4. 导入到 Excel
  5. 在"数据"→"分列"中选择"分隔符号"，勾选"连续分隔符号视为单个处理"
  6. 根据处理完之后的数据进行进一步的数据整理

导入数据技巧总结#

  1. 长段落复制技巧：Shift
  2. 分列技巧：固定宽度 / 分隔符号（其他：自定义）
  3. 替换技巧：信息末尾特定文本
    • ^p 分段符；||| 替换；灵活替换

格式技巧：规范不同格式的数据#

Excel 的格式类型#

  1. 常规 2. 数字 3. 货币 4. 会计专用 5. 日期（长/短日期）6. 时间 7. 百分比 8. 分数 9. 科学计数 10. 文本 11. 特殊 12. 自定义

Ctrl+1：快速进入格式的详细设置。

捣蛋鬼：文本形式的数字（无法计算、迷惑性强、隐蔽性强）。

文本转数字的方法#

  1. 逐个转换：左上角有小三角标记，靠近出现感叹号时，点击"转换为数字"，或出现列表时直接点击 C。注意：获取到数字之后用公式可能不会出现错误提醒（第一次不修改或双击不出现错误，或出现错误提醒后点击"忽略错误"会消失）。
  2. 分列转化：对于一列整齐的数据，直接分列一镜到底，"常规"。
  3. 1×选择性粘贴：当文本数据零散分散在整个单元格区域时，在数据表格之外的一个单元格中填入 1，复制这个单元格，选中需要转换的单元格区域，"选择性粘贴"。

需要文本形式的数字的情况：身份证、银行卡（数值超过 15 位）。使用文本格式：单引号 ' 强制文本格式。

日期格式的应用#

  1. 规范日期输入
  2. 间隔天数计算（和数值运算一致）
  3. 分列转换格式（分列一镜到底，"日期"）

自定义 & 特殊格式的应用（# 代表原来的数据）#

  1. 定小数位数
  2. 数字加单位（保留原来的数据格式，方便计算）
  3. 折算为万：0!.0,"万"
  4. 设置工号（工号总共有几位就打几个 0）
  5. 设置编号：00-00-00 或 00 00 00
  6. 评估等级：[>=90]"优";[>=75]"良";"差"
  7. 中文大写数字（会计常用）

清洗技巧：预处理、提取分离与校验（上）——预处理#

清洗的对象#

  1. 合并的单元格 2. 空行、空值 3. 重复值 4. 脏数据

重要技巧：每个选项后面带有字母，直接用 Alt+字母 即可选择这个选项而无需点击。

Ctrl+G：定位。

1. 合并单元格处理：

  • 选中合并了的单元格，取消"合并后居中"
  • "定位"→"空值"
  • 第一组数据的第一个空值等于第一个组数据的原先的值
  • Ctrl+Enter 即可自动填充函数
  • 针对散落无规律的合并单元格：Ctrl+F→"选项"→"格式"→"对齐"→"合并单元格"，即可查找到合并的单元格。选中添加颜色（注意：查找/替换中"格式"里的"合并单元格"勾选后需及时取消勾选，否则影响后续查找）

2. 空行检测：在数据表格右侧另起一列（辅助列），COUNTA() 函数计算非空单元格数量，再"筛选"出数量不正常的行。

3. 重复值：选中一列，"开始"→"条件格式"→"突出显示单元格规则"→"重复值"，进一步"筛选"；全选，"数据"→"删除重复值"（可选择需要哪几列的数据相同就删除）。

4. 脏数据清理：

  • 批注：全选后"开始"→"清除"→"清除批注"
  • 图片："定位"→"对象"

清洗技巧：预处理、提取分离与校验（下）——提取分离与校验#

数据的提取#

  1. 直接提取信息
  2. 提取并计算信息

日期提取：不能直接填入日期格式的数据（Excel 识别不了智能填充，个位数月日的 0 被自动省略）。在前几个单元格先提取出"文本格式"的数值，然后选中整列，Ctrl+E 智能填充，再用分列转换将文本转换为日期格式。

替代方法：选中需要提取数据的那一列，复制粘贴一列再选中，"分列"→"固定宽度"将日期段以日期格式提取出来。

日期时间计算：可以用 NOW() 函数，随时更新。

数据的分离#

针对更新频繁的数据：VLOOKUP 映射分离（用谁找→在哪找→在哪一列→精确或模糊）。

注意需要另起一张映射表：将需要映射的那一列数据复制粘贴过来，删除这一列中重复值，在旁加上每个数据值最终映射的数据即可完成映射表的创建。建议另起一个查询表（放在同一个文件）。

数据的校验#

  1. 检查错误与空值 2. 计数 & 数值计数 3. 数据验证功能
  1. Ctrl+G 定位→"公式"→"错误"/"空值"
  2. 右下角的提示栏内容，右键勾选"计数"和"数值计数"（"数值计数"不把表头算进计数范围），查看每一列数据数值计数的值是否相等，有助于发现格式问题
  3. 在填入数据之前进行设置："数据"→"数据验证"（限定输入数据类型或数值取值范围）→"序列"→"来源"跨表格引用，在另一个表格中填入需要的限定数据值，之后在原来指定的单元格区域中提供下拉菜单选择。可进一步做一级下拉菜单、二级下拉菜单的结构化处理。

展现技巧：颜色 & 图标，筛选 & 排序#

展现的友好性#

  1. 子表格重命名，不要 Sheet1/2/3
  2. 想让人看哪，就在哪退出
  3. 行高、列宽、字体要好看（完成数据处理后，选中所有列，双击一条边，即可自适应列宽）
  4. 表头配色，冻结首行（"视图"→"冻结窗格"→"冻结首行"），设置筛选

条件格式#

  1. 突出显示（<、=、文本包含、重复值、前后 10 项/10%、高/低于均值）："开始"→"条件格式"→"突出显示单元格规则"。删除：清除所选单元格规则。
  2. 数据条："开始"→"条件格式"→"数据条"；自定义设置：管理规则→编辑规则→设置最小值、最大值，控制正负占比。
  3. 图标集（饼图、星图、排名变动）："仅显示图标"。
  4. 色阶：化数字分析为图像感知。

筛选 & 排序#

  1. 文本筛选、数字筛选、日期筛选
  2. 自定义筛选 & 多条件筛选
  3. 关于 ? 和 * 字符
  4. 多条件排序："数据"→"排序"→"扩展选定区域"→"自定义序列"（用逗号隔开每一个值）

函数入门：基础操作与常用函数#

函数基础操作#

  1. 公式→插入函数→搜索想要的函数（对于复杂处理，此操作可减小工作量）
  2. 引用多个区域
  3. 相对引用、绝对引用（相对引用可能出错，F4 转换为绝对引用，或在行数与列数前都加上 $）
  4. 混合引用：固定列（$列）固定行（$行）

Excel 函数进阶#

函数进阶：复杂函数与案例实操#

VLOOKUP#

  • lookup_value（查找值）：用谁找
  • table_array（表格阵列）：在哪找
  • col_index_num（所在列数）：在哪列
  • range_lookup（查找方式）：精确 0 / 模糊 1

注意：模糊匹配时，被查找的区域（表格阵列）一定需要升序排列。

多条件查找#

建立辅助列，用 & 符号合并条件。注意辅助列一定要建在表格阵列的第一列。

VLOOKUP 与 HLOOKUP：

  • [V] Vertical 垂直，查找列，竖着找
  • [H] Horizontal 水平，查找行，横着找

MATCH#

MATCH(lookup_value, lookup_array, Match_type)

查找值、搜索区、精准匹配 0。帮助你返回在这一行或这一列的具体第几行/第几列。

综合 VLOOKUP 函数：MATCH 里面的 lookup_array 和 VLOOKUP 里面的 col_index_num 相对应，解决无法确定哪一列的问题。

IF 与 IFS 函数#

IF：IF(Logical_test, Value_if_true, Value_if_false)逻辑条件、True 的返回值、False 的返回值。可以无限嵌套。

IFS：IFS(Logical_test1, Value_if_true1, Logical_test2, Value_if_true2, ...)逻辑条件 1、条件 1 是 True 的返回值、逻辑条件 2、条件 2 是 True 的返回值...

数据透视：逻辑理解与制作步骤#

创建数据透视表（插入→数据透视表）#

  1. 每列必须有表头
  2. 拖拽字段，做出你想要的透视表
  3. 移动、清除维度、删除整个透视表
  4. 字段列表的显示和隐藏
  5. 更友好的显示方式：更多维度集中在"行"

易错点：

  1. 不能覆盖另一个数据透视表
  2. 透视表不会自动更新数据，需手动刷新
  3. 使用"更改数据源"功能修改数据选取范围

理解数据透视表#

  1. 理解：行、列、值、筛选（"筛选"不能选择已经位于"列"或"行"的维度，可用"插入"→"切片器"实现相同功能）> "值"默认是求和值，右边下拉框可选择运算函数，其他同理，可选择维度范围。
  1. 下钻思维：叠加拖入更多字段
  2. 理解字段排序逻辑，善用"其他排序选项"

数据透视表进阶：多维透视表与案例分析#

注意："条件格式"中的"最前/最后规则"中的"高于平均值"，针对所选单元格区域中存在的空值，Excel 会自动忽略（不参与平均值计算，也不会被标记）。Excel 逻辑：条件格式 = 先判断 → 再决定是否应用格式；空值连"判断"这一步都不会参与。

Ctrl+Shift+8：选中"当前数据区域"，Excel 会把一块连续有数据的区域当作一个整体。满足条件：中间没有空行、空列；数据是连在一起的。

值的显示方式#

Power Query 数据清洗与自动化更新#

修整与清除#

  • 修整：从所选列的每个单元格中删除前导空格与尾随空格。转换→文本列→格式。
  • 清除：删除所选列中的非打印字符。转换→文本列→格式（最好先清除再修整）。
  • 每个字词首字母大写：如名。

数据类型转换#

和 Excel 内的表格规则类似，但是 Excel 里面的大多数快捷键都失效。

合并列与拆分列#

  • 先选哪一列，哪一列就在合并后的左边
  • 对于数据安全性，"添加列→合并"相比"转换→合并"，合并之后得到的是一个新的列，而非修改原有的列
  • 拆分列在"按位置"的情况下，前面必须为 0，否则会丢失前面第一段分隔出来的数据

提取列信息的 2 种方法#

"转换→提取" / "添加列→提取"。自定义做法：范围。注意："转换"板块和"添加列"板块的区别在于对原始数据的保留与否。

多表格合并追加与自动更新#

  • "主页→新建源"导入相关的表格
  • "合并"：合并为新查询→选择好表格后，多选两个表的相同维度的列（注意选择的顺序要一致）→下方出现"所选内容匹配第一个表的 XX 行"→确认后，在第一个表的基础上出现新的一列，选择两个表不重合的维度即可添加合并
  • "合并查询" vs "追加查询"：合并是将多个表的同一列的不同维度的数据合并在一张表的同一列，常用于具有相同对象、不同维度的多个表格；追加是在第一个表的基础上追加其他表的数据，不同维度数据展现在不同列，其他维度显示空值，更常用于多个具有相同维度的表格汇总
  • 自动更新：源数据发生改变，对 Query 已上载的数据表右键"刷新"即可

Power Query 逆透视 & 分组依据#

  • 透视：一维转二维（升维）
  • 逆透视：二维转一维（降维）
  • 不要聚合：保留文本结果
  • 分组依据：快速生成关键结果（主页→转换→分组依据）
  • "添加列→自定义列"：添加一个经过函数运算后的数据

Power Pivot 多表数据建模#

Pivot 特性#

  • 可融合多个数据表（无需 VLOOKUP 函数）
  • 可多表关联搭建复杂数据模型
  • 一次建模，一键刷新
  • DAX 函数编写公式计算
  • 可将数据模型轻松移植到 PBI 和 SQL 中

注意#

  • 在导入其他表时，最好勾选"使用第一行作为列标题"
  • 最好对导入的表进行重命名（小技巧：每个文件名前面以数字为前缀，方便后期导入）
  • 记住"一对一/一对多"的对应关系，不可"多对多"（关系图视图模式下）

Power Pivot 透视表分析与 KPI 设置（上）#

  • 透视表构建：选取有关联的指标
  • 辅助列：辅助排序（设置月份时可能存在"文本"导致呈现的顺序并非时间，可回到 Pivot 界面建立辅助列）
  • 切片器：多维度呈现（多表不同维度的调用需要查看两个维度之间所在的表在 Pivot 中是否具有直接关系）

维度和度量#

维度#

分类字段如名称、国家、地区等，一般非数字。

度量#

数值字段，如销量、利润、折扣等，一般是数字。

字符串、日期格式默认为维度。

数据桶#

连续型数据离散化后默认设为维度。如 0,1,2,3,4... 属于度量，但分成 0-10, 11-20, 21-30... 后为数据桶可变成维度。

将度量拖入到"标记"中，可以根据不同种类进行标记。"仅保留"和"排除"可以添加筛选器，双击筛选器中添加的条件可以做进一步设置。

度量名称和度量值#

  • "度量名称"包含所有的维度
  • "度量值"包含所有的度量

当同时展示 2 个或 2 个以上的维度或度量时，会自动创建"度量名称"和"度量值"。

注意：拖入度量值时，拖进"标记"和直接拖到右边的表格，二者效果是不同的，当添加标记之后，右边栏可以进行标记格式的设置。

建库#

新手流程#

第一步：建库（项目空间）

CREATE DATABASE my_project;

第二步：创建账号

CREATE USER 'lemishui'@'%' IDENTIFIED BY 'xjl344136';

第三步：给账号权限

GRANT ALL PRIVILEGES ON my_project.* TO 'lemishui'@'%';

如果是所有库，则 my_project 改为 *。

第四步：刷新

FLUSH PRIVILEGES;

注意：MySQL 的权限是"叠加的"，不是"覆盖的"。如果之前赋予过全局权限，那么会一直拥有全局权限（权限会一直累加，除非 REVOKE）。

撤销权限：

REVOKE ALL PRIVILEGES, GRANT OPTION FROM 'lemishui'@'%';

建库语法#

CREATE DATABASE [IF NOT EXISTS] <数据库名>
[[DEFAULT] CHARACTER SET <字符集名>] [[DEFAULT] COLLATE <校对规则名>];

字符集（CHARACTER）和校对规则（COLLATION）#

字符集是用来定义 MySQL 存储字符串的方式，校对规则定义了比较字符串的方式，解决排序和字符分组的问题。

看得懂命令行（CLI），不需要去背它，主要是 GUI 操作。树形结构里面的源头是服务器，展开之后才是数据库。

字符集：决定能够存放信息的范围大小，只能做到由高到低降级，不能做到由低到高升级（例如从 UTF8 降到 ASCII 可以，从 ASCII 升到 UTF8 不行），所以改动或做迁移时必须做字符集评估。

建表#

利用 CREATE TABLE 创建表，必须给出：

  • 新表的名字，在关键字 CREATE TABLE 之后给出
  • 表列的名字和定义，用逗号分隔

主键：值必须唯一。如果主键使用单个列，则它的值必须唯一；如果使用多个列，则这些列的组合值必须唯一。主键中只能使用不允许 NULL 值的列。

UPDATE house a

ON a.ParcelID = b.ParcelID
AND a.UniqueID <> b.UniqueID
SET a.PropertyAddress = b.PropertyAddress
WHERE a.PropertyAddress IS NULL;

作用域和生存期#

  • 作用域：表示变量在程序中能被使用的范围，由创建变量的位置决定
  • 生存周期：表示变量在程序运行过程中，具有实际意义的值的时间范围
  • 变量的作用域是变量名字的性质（语法性质），生存周期是变量本身的性质；进入作用域，变量开始它的生命周期，离开则结束
  • 变量名字的作用域会影响它的生存周期
  • 变量的作用域尽可能小，是一个好的编程方式
  • 全局变量：在程序中任何一个地方都能引用的变量
